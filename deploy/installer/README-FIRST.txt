GHOST installer (one Windows PC, no internet needed after install)

1. Copy this whole folder to the PC (USB drive is fine). Do not move files out of it.
2. If the PC has no SQL Server: put the Microsoft "SQL Server Express" installer file (SQLEXPR_x64_ENU.exe) into the prereq folder first.
3. Open the installer folder, right click Install-GHOST.cmd, choose "Run as administrator".
4. Follow the questions on screen. It never touches an existing database.
5. Use the GHOST icon on the Desktop.
Full guide: docs\INSTALL-GUIDE.md. Test checklist: docs\CLEAN-MACHINE-TEST-CHECKLIST.md.
