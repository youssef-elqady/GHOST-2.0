## Decisions taken by the user in this session

- A running session is never cut off by shift close or handover (no FR-13 block).
- Staff must not re-login every few minutes: access JWT is short-lived, a 7-day sliding refresh cookie (30-day cap) renews it silently.
- Expenses and withdrawals share one ledger table with a Category column (accepted for now).
- Payments are cash only for v1.

## Known shortcuts (honest list)

1. Single cash ledger instead of separate Expenses and Withdrawals tables.
2. Invoice number counter does not reset per year.
3. Device revenue in reports is an estimate by time share.
4. CSV export instead of real Excel and PDF files.
5. Print count is audited; there is no PrintJobLog table.
6. Discounts are Admin-only; a Staff discount request flow does not exist.
